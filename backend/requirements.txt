# Easiest Approach: Copy Key Files Manually

I'll show you the content of the essential files so you can create them on your local computer. This is the simplest method for getting your project working.

## Step 1: Create the Project Structure

First, create the following folder structure on your computer:

```
passive-fire-app/
├── backend/
│   └── uploads/        (empty folder)
└── frontend/
    ├── public/
    └── src/
        ├── components/
        └── services/
```
